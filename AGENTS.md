docked sibling on desktop with Sheet on small screens; rail styling and top edge align with the tracker (no offset); group by client with a quiet per-task meta row (assigner avatar, self as exact `me` and others avatar-only, plus tracked-vs-estimate time with error styling when over estimate, and project name); My Tasks titles open/toggle a cover-slide task thread over tracker + entries (rail stays; title click is thread-only, not select/play)—chat-first with a visible compact task header (not buried under tracker), industry-standard max-width column, and Orch-in-thread via composer badge (not the global Orch dock as the chat surface); project/client pickers reuse the tracker task-chooser pattern; create-form task chooser sits on its own line with remaining controls on a second line; Add is a full-width `Add` button (no dropdown arrow) using the primary theme color, becoming `Update` when the selected task already exists; - Optimistic UI must not flicker or diverge from server/cache truth; for critical task/timer CRUD, prefer DB/cache-confirmed updates over local-only optimistic state; Agency task-chooser infinite query keys include an `infinite` segment before `catalog`/`search`—cache patches must treat any key containing `infinite` as `{ pages }` shaped, never list-shaped, or create-task optimistic patches corrupt Tracker; focused tracker/description inputs must not stutter or lose edits from live timer or cache sync while typing; timer start/stop must queue (no silent drops); pending/saving and stop blockers must be visible and accessible; picking a description suggestion must flush so mid-track description sync does not stick.
