# Bills Table Actions Column Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a trailing Actions column on Agency Money Bills tables (Clients, Team, Adjustments, Expenses) that shows the settlement CTA when remaining is open, plus a details icon that opens the existing detail sheet.

**Architecture:** Pure settle-label helpers decide when a CTA exists. A presentational `MoneyTableActionsCell` renders outline settlement + ghost details. Tables pass existing hook callbacks (`onOpenAdjust`, `onOpenPayment`, `onMarkPaid`, `onOpenSalaryPool`, `onOpenRow`). No API, schema, or dialog changes. Uncollect / Refund / Preview / Export / Dismiss stay in the sheet.

**Tech Stack:** React 19, shadcn `Table` / `Button` / `Tooltip`, lucide `PanelRight`, Bun test, golden-file views.

## Global Constraints

- **Worktree:** `/home/omar/Projects/brainiac/.worktrees/bills-tables` on `feat/bills-tables`. Do not edit the main checkout.
- **Operate mode:** incumbent DESIGN.md (quiet instrument, shadcn tokens, product language `amount`, no em dashes in UI copy).
- **Row click and details icon both open the sheet.** Settlement buttons `stopPropagation`.
- **Settlement in the column only when remaining is open** (`remainingAmount > 0` for bills; `canRecordPayment` for expenses). Labels: Collect / Pay / Record / Record payment / Mark paid. Uncollect, Refund, Adjust, Preview, Export, Dismiss stay in the sheet.
- **Salary-pool exception:** there is no Pay dialog. Column Pay opens the existing salary-pool sheet (amount field lives there).
- **Details icon:** lucide `PanelRight`, `aria-label="Details for {title}"`, tooltip `Details`, `aria-haspopup="dialog"`. Always visible (not hover-only).
- **Settlement button:** shadcn `Button` `size="sm"` `variant="outline"`, labeled, never icon-only. Disabled when `isMutationPending`.
- **Views stay presentational.** No oRPC, stores, or auth in `*-view.tsx`.
- **No new visual world.** Do not reintroduce table party `Link`s or the All expenses catalog.
- **Checks:** `bun test` for new helpers; `bun run check`; `bun run check-types`; `bun run check:conventions`; `bun run check:golden` after adding `agency-money-table-actions-view.tsx`.

  remainingAmount: number;

  canMarkPaid: boolean;

  if (row.canRecordPayment) return "Record payment";
  if (row.canMarkPaid) return "Mark paid";
  return null;
}

- [ ] **Step 1: Create the view**

Create `apps/web/src/features/money/agency-money-table-actions-view.tsx`:

```tsx
import { type MouseEvent } from "react";
import { PanelRight } from "lucide-react";

import { Button } from "@/ui/button";
import { TableCell } from "@/ui/table";
import { Tooltip, TooltipContent, TooltipProvider, TooltipTrigger } from "@/ui/tooltip";

function stopRowClick(event: MouseEvent<HTMLElement>) {
  event.stopPropagation();
}

export function MoneyTableActionsCell({
  settleLabel,
  settleDisabled,
  onSettle,
  detailsLabel,
  onOpenDetails,
}: {
  settleLabel: string | null;
  settleDisabled: boolean;
  onSettle?: () => void;
  detailsLabel: string;
  onOpenDetails: () => void;
}) {
  return (
    <TableCell className="text-right">
      <div className="flex items-center justify-end gap-1">
        {settleLabel && onSettle ? (
          <Button
            type="button"
            size="sm"
            variant="outline"
            disabled={settleDisabled}
            aria-haspopup="dialog"
            onClick={(event) => {
              stopRowClick(event);
              onSettle();
            }}
          >
            {settleLabel}
          </Button>
        ) : null}
        <TooltipProvider delayDuration={120}>
          <Tooltip>
            <TooltipTrigger asChild>
              <Button
                type="button"
                size="icon-sm"
                variant="ghost"
                aria-label={detailsLabel}
                aria-haspopup="dialog"
                onClick={(event) => {
                  stopRowClick(event);
                  onOpenDetails();
                }}
              >
                <PanelRight className="size-3.5" aria-hidden />
              </Button>
            </TooltipTrigger>
            <TooltipContent side="left">Details</TooltipContent>
          </Tooltip>
        </TooltipProvider>
      </div>
    </TableCell>
  );
}
```

No component render test (golden testing: pure logic only).
